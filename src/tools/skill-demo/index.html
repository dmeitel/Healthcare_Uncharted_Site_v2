How a skill loads: three levels

Skills load in three levels, and only what's needed. This is called progressive disclosure, and it's why an agent can have hundreds of skills available without drowning in them. The levels light up below as the agent moves through them.

Level 1: Metadata

Just the skill's name and a one-line description. Always in view, costs almost nothing. This is how the agent knows the skill exists.

Level 2: SKILL.md body

The full instructions. Loaded only when the task matches the description. Your protocol, read at the moment it's needed.

Level 3: Bundled resources

Reference files, templates, scripts. Pulled in only if the instructions point to them. Most runs never touch this level.

The outputs above are simulated for illustration, but the loading mechanics are real: this is how Claude Code, Cursor, and other agents that follow the Agent Skills spec handle skills. The skills named here are ones I wrote for my own team; the field guide explains them and how to write your own.

Skills can execute code in your agent's environment. Audit anything you install, and keep unvetted community skills away from machines that touch clinical systems.
