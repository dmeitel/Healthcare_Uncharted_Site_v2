# Schools cross-check

Generated by `npm run check:schools` on 2026-10-03. Do not edit by hand; re-run it.

The Schools layer of the Hospital Operations Map comes from IPEDS, 2023-24, Provisional release. This holds it against the accreditors' own lists, read the same day:

- LCME, Accredited U.S. Programs: https://lcme.org/directory/accredited-u-s-programs/
- AACOM, U.S. Colleges of Osteopathic Medicine: https://www.aacom.org/explore-med-schools/choose-do-explorer?startRow=0&rowsPerPage=200
- ARC-PA, Currently Accredited Programs: https://www.arc-pa.org/entry-level-program/currently-accredited-programs/
- CoARC, Accredited Programs: https://coarc.com/students/find-an-accredited-program/print-accredited-programs/
- CCNE, Accredited Programs (by state): https://directory.ccnecommunity.org/reports/accprog.asp
- ACEN, Search Programs: https://www.acenursing.org/search-programs/

Nurse practitioner programs are not checked; no accreditor lists them apart from other master's tracks.

Where each accredited program lands:

- On the map: the school graduated people in it in 2023-24, and the map shows them where the program is.
- Counted at another campus: graduated people, but IPEDS files them under a campus more than 30 miles away, or in another state.
- No graduates that year: in IPEDS, with nobody graduating in the program in 2023-24. Mostly new programs; an older one is worth a look.
- Graduates at another level: the school reports the program, at a level the map does not count.
- Not in IPEDS: the federal data has no such school.
- Unsure: the names are too far apart for the matcher to call.
- On the map, no accreditor: a program the map shows that no list carries (closed since, renamed, or a code filed oddly).
