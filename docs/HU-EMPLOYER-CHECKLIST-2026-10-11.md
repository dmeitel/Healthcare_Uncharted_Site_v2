# Before the first post · an employer-safe checklist

Written 2026-10-11 from the Ideas card "An employer-safe launch checklist" (David's Yes). David clears this before
the LinkedIn teaser on October 21. The policies are on his employer's intranet, which the research could not read, so
the first three lines are his to do; the rest Claude can check in the repo on request.

- [ ] Read the social media policy.
- [ ] Read the outside activity (outside employment) policy.
- [ ] Read the conflict of interest policy, and whether income from a support link (Ko-fi, currently off) has to be
      disclosed.
- [ ] Keep the independence line: the About page says the site is an independent educational project, not
      affiliated with or endorsed by his employer, and names the employer; the new disclaimer page (/disclaimer/) says
      the views are his own and names no employer.
- [ ] No internal screenshots, logos, data or names of internal systems in any post or page.
- [ ] Run each post through the patient information check (`npm run writing`, paste the draft).
- [ ] Decide whether "worksFor: Intermountain Health" stays in the site's structured data on every page. It is
      accurate and helps a reader trust the author, and it also ties the employer's name to every page, which some
      policies care about. (It lives in src/_includes/base.njk.)
- [ ] For the broken arm piece (in the secret menu): the manager's read comes first (DECISIONS R1 and R6).

Reference: AMA Code of Medical Ethics, Opinion 2.3.2, professionalism in the use of social media
(code-medical-ethics.ama-assn.org, checked 2026-10-11).
